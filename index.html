Format JSON attendu — schéma CentraScan-Wifi

Schéma wifi-scanner/v1 généré par CentraScan-Wifi. Sections requises : scan.networks, current_association, capture. Section optionnelle : diagnostics (réutilisée si présente). 

{
  "schema": "wifi-scanner/v1",
  "version": "1.0.0",
  "timestamp": "2026-05-10T08:48:58Z",
  "host": { "hostname": "MacBook-Pro.local", "wifi_interface": "en0" },
  "current_association": {
    "ssid": "<redacted>", "rssi": -38, "channel": 100, "tx_rate": "1200"
  },
  "scan": {
    "method": "system_profiler",
    "count": 12,
    "networks": [
      { "ssid": "<redacted>", "rssi": -37, "channel": 100, "security": "WPA2 Personal", "associated": true },
      { "ssid": "<redacted>", "rssi": -77, "channel": 11, "security": "WPA2 Personal" }
    ]
  },
  "capture": {
    "interface": "en0",
    "duration_seconds": 31,
    "total": 34,
    "mdns": 34,
    "ssdp": 0
  },
  "diagnostics": {
    "channel_congestion": [ { "channel": 100, "count": 2, "ssids": [ ... ] } ],
    "weak_networks":      [ { "ssid": "...", "rssi": -93 } ],
    "security_summary":   { "WPA2 Personal": 10, "WPA2 Enterprise": 2 }
  }
}

► Bandes déduites du canal : 1-14 = 2,4 GHz · 32-177 = 5 GHz · > 177 = 6 GHz
► Client Behavior : évalué sur la machine de scan (current_association)
► Broadcast/Multicast : pps calculés à partir de capture.duration_seconds
